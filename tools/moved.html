This repository has moved

The SurfHost OPNsense plugins, including os-openvpn-auth-oauth2, are now published at surfhost.github.io/opnsense-repo.

Firewalls that update os-openvpn-auth-oauth2 to 1.7.1 or later switch over by themselves. On any other firewall, run this in a root shell:

fetch -o /usr/local/etc/pkg/repos/surfhost.conf \
    https://surfhost.github.io/opnsense-repo/surfhost.conf
pkg update

This address keeps serving os-openvpn-auth-oauth2 for a while, so nothing breaks in the meantime.
