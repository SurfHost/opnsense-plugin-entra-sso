SurfHost OPNsense plugin repository

Package repository for OPNsense plugins published by SurfHost. Add it on your firewall, then install the plugins from System > Firmware > Plugins as usual.

fetch -o /usr/local/etc/pkg/repos/surfhost.conf \
    https://surfhost.github.io/opnsense-plugin-entra-sso/surfhost.conf
pkg update

Available plugins

  • os-openvpn-auth-oauth2 — Microsoft Entra ID single sign-on for OpenVPN (source and documentation)
Hosted from the gh-pages branch of SurfHost/opnsense-plugin-entra-sso.
